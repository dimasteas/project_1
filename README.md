Виджет для обработки банковских операций клиента. Предоставляет функции фильтрации по статусу и сортировки по дате.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/dimasteas/project_1.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd project_1
   ```
3. Зависимости отсутствуют, дополнительных действий не требуется.

## Использование

### Модуль `src.processing`

#### `filter_by_state(operations, state='EXECUTED')`

Фильтрует список операций по значению ключа `state`. Если ключ отсутствует в словаре, операция пропускается.

- **Параметры:**
  - `operations` — список словарей с данными операций.
  - `state` — строка статуса (по умолчанию `'EXECUTED'`).
- **Возвращает:** список словарей, у которых `state` соответствует заданному.

#### `sort_by_date(operations, descending=True)`

Сортирует список операций по ключу `date`.

- **Параметры:**
  - `operations` — список словарей (обязательно наличие ключа `'date'`).
  - `descending` — порядок сортировки: `True` (по умолчанию) — от новых к старым, `False` — от старых к новым.
- **Возвращает:** отсортированный список.
